## 2. Amendment (audit only; selection unchanged)
- **The audit key is `rule`, and `reason` is only a reporting label.** A C1 reject is `rule == "C1"`
  (`ra.is_c1_reject`). A reject row with no rule, or a C1 row with a non-C1 reason, is a STOP.
- **B1 (council biostat, neuro, QA): no `equal` across C1 classes.** `audit_pair` now STOPs whenever both rows
  are rejects and exactly one of them is a C1 reject. This check comes before the `equal` test, so a pair
  such as C1/personality_rights against B4/personality_rights or F7/personality_rights STOPs in both
  directions.
  - `dry_pair` reaches the same check through `audit_pair`.
  - Tests: tests/test_refstim_d081.py.
- **Stop evidence.** An audit STOP writes `<log>.stop.json` holding the full row before it raises
  (unchanged from the draft).
- **No separate reason code for F7/B4.** This was unanimous: a new code would edit the frozen
  `reject_reasons` and create reason mismatches against the v1 and v3 logs.
  - Instead, a test derives from the frozen map every reason that C1 shares with a non-C1 rule (today only
    `personality_rights`). It requires classification by rule and a STOP for each such cross-class pair.
- **Unchanged:**
  - `evaluate_image` and every filter, threshold and ordering;
  - the first-20 rule, `rule_reasons`, `reject_reasons` and the flip list;
  - `stop_resolution` and `audit_revid_drift`;
  - the C3 preload order (face → body → place) and D-078.
