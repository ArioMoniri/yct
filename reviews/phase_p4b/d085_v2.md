## 2. Twin identity and decoded differences (council (d))

The gate stays on rendered uint8 frames outside [o−4, o+8). Per LOC clip the QC also reports, never gating
and with no x264 tolerance: decoded LOC vs LOC_SCR max|Δ| and the mean fraction of differing pixels outside the
windows (`twin_decoded`), and decoded vs rendered max|Δ| / PSNR at each event mid-frame (`decoded_vs_rendered`).
`row_pass` ignores every check marked `gating: false`.

## 3. Speech corpus

- **Licence:** copyright not cleared; not asserted public domain (IEEE Std 297-1969; 1992 automatic renewal;
  short phrases, 37 CFR 202.1(a); ≤ 93 sentences synthesised). Recorded in `docs/stimuli/LICENSES.md` and
  `speech.licence_status`.
- **Public/private split:** `speech_corpus_v1.json` holds (list, item, sha256) only, plus the raw page sha256.
  The raw page is `speech.private_raw_s3`; `resolve_texts` re-parses it at build time and stops on any raw or
  item sha mismatch. Selection logs and word-timing tsvs carry text, so they stay private; `public_record`
  strips text from anything committed. Corpus sha (not frozen): 252c83ac…40c3.
- **SPK:** 3-word leads only at 175 wpm (`speech.spk_words: 3`; the `spk_words_rule` is removed). Selection
  logs per-family pass rates (tried/kept) for the report. Exhaustion is still a STOP. No test synthesis before
  the freeze.
- **SPK/BURST audio gate (council (c)), constructive on the rendered 48 kHz audio** (the int16 samples the
  builder writes before encoding; the 16 kHz sidecar is resampled, so it cannot be sample-identical):
  (1) every sample outside the utterance windows equals the GREY_CTRL rendering; (2) the whole clip equals
  `place_speech` applied to the bed with each logged (onset, utterance), so each utterance sits sample-exact at
  its logged onset. The per-window RMS ratio is reported (it is matched by construction).
- **speech_envelope never gates** (matched-RMS replacement gives no a-priori sign). Reported: event/non-event
  ratio and point-biserial r. The BURST kernel ⊗ envelope correlation uses each utterance's own pre-mix Hilbert
  envelope.
- **T-ENV order:** no SPK/BURST/TALKFACE build until `refclips_d085.speech`, `refclips_d085.talkface`, the corpus
  sha and `refclips_d085.tenv` (module + blob sha1) are frozen (`speech_build_preconditions`). T-ENV does not
  block the visual rebuild.

## 4. TALKFACE (council (e))

- **Weights:** `wav2lip.pth`, chosen 3–2 (referee, neuro, QA: the README's more accurate lip-sync, and mouth
  timing is the construct; watchdog and biostat preferred the README default `wav2lip_gan.pth`). Run at
  `--fps 30`. URL, fetch date and sha recorded at T-TALK setup; no author-published hash exists.
- **Mirror:** weights, s3fd detector and the clip live only in `talkface.mirror_s3` (private). The repo records
  shas only (weights, s3fd, README).
- **internal only:** `publish: false` (schema refuses true), `synthetic_label: true`; mouth synthesised at 96 px
  with no head motion or blinks, disclosed.
- **Face rule:** the first face pass after v4 rank 492, in log order (disjoint from the 20 LOC faces). Its
  licence comes from the frozen image_licences (all permit adaptation, none ND). On a technical failure
  (s3fd finds no face, Wav2Lip error, licence not adaptable) the next pass is taken, logged, with no visual
  review; 5 skips is a STOP to the owner (`talkface_face`). A match with a LOC identity in the source metadata
  is disclosed.
