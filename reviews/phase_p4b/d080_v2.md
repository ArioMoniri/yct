## A. Commons revision drift after the dry audit (watchdog B1)

Config `controls.refclips_d080.stop_resolution.audit_revid_drift:
current_revision_stands_log_both_resume_next_rank`, stated before the run:

- The dry audit records, for every audited title, the revision it read (`read_revids`: sha256(title) →
  revid, per category).
- In the v3 run, a pair the audit would STOP on is resolved as `revid_drift` if and only if the v3 row's
  `read_revid` differs from **both** the superseded row's revision (`read_revid` for v2 rows, the snapshot
  `revid` for v1 rows) **and** the dry-audit revision for that title. The page was then edited after the dry
  audit: the current-revision decision stands, the run resumes at the next rank, and no v4 follows.
- The row logs `audit_revid_drift`: per superseded log, the superseded revid, the dry-audit revid and the
  superseded (decision, reason). `finalise` writes `data/refstim/image_revid_drift_v3.json` (rows, or
  "none") for the v1 report.
- Not exempt: a title absent from the dry audit; a row whose `read_revid` equals the dry-audit revid (the
  dry audit already judged that revision, so a mismatch is a real defect: `other_audit_stop` applies); a row
  whose `read_revid` equals the superseded revision.
- The rule never selects: it only decides whether a non-matching audit pair is a STOP. The decision of every
  row is the frozen D-075/D-079 decision at the revision actually read.

## B. Launch rule enforced in code (referee B1, biostat a–c)

`ra.check_dry_audit` runs in `refstim_auto_run.py run` after `run_commit` is known and before rank 1. It
STOPs unless:

1. `sha256(data/refstim/d080_dry_audit.json)` equals the frozen `dry_audit_sha256`;
2. every category with superseded logs is present, and every superseded log of that category is audited;
3. `would_stop == []` in every category;
4. the file names its `code_commit`; and
5. no file matching `src/yct/curate/refstim*.py` or `scripts/refstim_d080_dry_audit.py` differs between
   `code_commit` and the run commit (`git diff --name-only`). Any later change to these files means re-running
   the dry audit and setting its new sha before the freeze.

The dry-audit script itself refuses to run with uncommitted changes in those paths, so `code_commit`
describes the code that produced the file. Tests: `tests/test_refstim_d080_council.py` (one per refusal).
